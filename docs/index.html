CORE PRINCIPLES

五大核心规则

兼顾排版整洁与技术汇报信息密度，改写法不篡改原稿里的任何真实数据与边界。

01

汉字与英文、数字紧挨

清除中文与拉丁字母、阿拉伯数字之间的机械空格，如Qwen3-4B、177.73tok/s、3个；英文词间空格（如Spec V2、Online FP8）照常保留。

02

去掉前缀套娃与装饰符

保留标题层级与分组，砍掉每条复读的**模块名**：说明前缀、✅🚀📌等装饰emoji和普通名词双引号，长短按事情重要度自然区分。

03

只留动作与可验证结果

删掉“显著提升、稳步推进、奠定坚实基础”等无数字支撑的空话，删掉公文开头结尾；风险项写明卡点、缺口资源与需要拍板的事项。

04

黑话降维与成果前置

顶部单列主要进展；当方向切换时先摆评测数据说明“为什么转”。把内部类名、参数flag、生僻简称译成通用工程表达，裁掉commit哈希与早期单步loss噪音。

05

先探活再挂看板链接

涉及实验对照或画廊时，先探测本地监听端口并确认HTTP返回200，再将真实URL作为Markdown链接挂到对应章节，绝不凭记忆硬拼死链。

SAFE

严格保护区原样不动

YAML frontmatter、围栏代码块、单/多反引号行内代码、文件路径、URL、邮箱、逐字引用和带空格官方专有名词全程跳过，绝不粘连或损坏。

BEFORE & AFTER

典型改写对照

覆盖常规周报去套话、风险直写，以及复杂技术周报的术语降维与目标转向重构。

CLI & AUTOMATION

配套脚本与仓库集成

scripts/check_spacing.py仅依赖Python标准库，可直接接进本地检查、管道或CI门禁。

1. 安装到Agent技能目录

git clone https://github.com/caseclose/human-format.git ~/.cursor/skills/human-format
# 或 Claude Code 目录：
cp -r ~/.cursor/skills/human-format ~/.claude/skills/human-format

安装后在写周报、月报或向上同步时会自动触发，也可以直接点名“用human-format润色这段周报”。

2. 检查、管道与原地修复

python3 scripts/check_spacing.py report.md
cat draft.md | python3 scripts/check_spacing.py -
python3 scripts/check_spacing.py --fix report.md

检查模式命中多余空格时返回退出码1，方便直接挂入pre-commit或GitHub Actions。

3. 局部豁免注释

<!-- human-format:off -->
故意展示的 错误 1 次示例
<!-- human-format:on -->

单行跳过示例 1 次 <!-- human-format:ignore -->

仅HTML注释指令生效，正文里提到指令字面量不会误关检查。
